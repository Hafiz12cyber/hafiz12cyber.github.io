🎯 What is kevala?

kevala is a revolutionary tool that brings sophisticated decision models (Laya and Kev) to any web page. Imagine being able to run machine learning classification, set up LLM guardrails, or implement complex decision-making logic — all directly in your browser, with lightning-fast performance. That's exactly what kevala does.

Built on a powerful Rust engine compiled to WebAssembly, kevala delivers native-level performance without requiring any server infrastructure. The integration of WebGPU kernels means your computer's graphics processor helps accelerate computations, making everything run smoothly even with complex models.

📖 How to Use kevala

Using kevala in your web projects is incredibly straightforward. Here's a simple example to get you started: 

<script type="module">
    import { Kevala } from './kevala.js';
    
    // Initialize kevala
    const kevala = new Kevala();
    
    // Load a decision model
    await kevala.loadModel('laya');
    
    // Make a decision
    const result = await kevala.decide({
        input: 'Your data here'
    });
    
    console.log(result);
</script>

That's all it takes! With just a few lines of code, you can integrate powerful decision-making capabilities into any web page.
